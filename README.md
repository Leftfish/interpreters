# Python practice: interpreters

Practice supposedly makes perfect so let's try to write interpreters in Python.

* 21-23.07.2020: [brainfuck.py](brainfuck.py) - a simple Brainfuck VM. Many thanks to [Maciek Jabłoński](https://github.com/maciekjablonski) for his helpful suggestions on how to make the code more consistent with OOP principles.
* 29.12.2020-17.01.2021: [intcode.py](intcode.py) - an Intcode Computer from [Advent of Code 2019](https://adventofcode.com/2019) rewritten from scratch to make use of some things I've learned since 2019
* 2.05.2025: [simple_assembler.py](simple_assembler.py) - an interpreter of assembler written over two evenings to solve a [2-kyu Codewars task](https://www.codewars.com/kata/assembler-interpreter-part-ii/), and mainly to prove to myself that after 5 years I haven't forgotten everything. The test suite is from there and I was too lazy to add them via pytest or any other similar tool.
